Valaxy 1.5.2 improves default SEO and answer-engine metadata, refines Markdown `details` disclosure styling, smooths the Yun back-to-top progress indicator, and fixes component cover fallback image rendering and stale lazy route chunk recovery.

## Core & SEO

- Only render the fallback `<img>` in `ValaxyCover` when `coverComponent` is missing or fails, preventing underlying cover images from bleeding through rounded corners or loading unnecessarily when a component cover is active. [#839](https://github.com/YunYouJun/valaxy/pull/839)
- Recover automatically when Vue Router fails to load a retired lazy route chunk after a deployment by navigating once to the resolved same-origin destination. [#838](https://github.com/YunYouJun/valaxy/pull/838)
- Improve default SEO and answer-engine metadata: write `lastmod` to `sitemap.xml` and exclude `noindex` routes, consolidate `BlogPosting`/`Article` JSON-LD in core linked to `#identity` with page-scoped `@id`, `path`, and `inLanguage`, add `BreadcrumbList`, emit RSS/Atom `rel="alternate"` head links when RSS is enabled and `siteConfig.url` is configured, add `siteConfig.seo.ogImage` and `siteConfig.seo.pagination` (`/page/1` canonicalizes to `/`, `/page/2+` defaults to `noindex, follow`), add opt-in `features.imageAltFallback` (default `false`), and exclude image URLs from `sameAs`. [#842](https://github.com/YunYouJun/valaxy/pull/842)

## Yun theme

- Refine Markdown `details` disclosure container UI and transitions. [#841](https://github.com/YunYouJun/valaxy/pull/841)
- Smooth the back-to-top progress indicator with scroll-driven animation.
- Ensure a single semantic `<h1>` on the homepage (Nimbo site title, Strato accessible banner heading with fallback, and `/page/n` sr-only heading), downgrade filtered tag/category card headings to `<h2>`, and render site subtitles as `<p>`. [#842](https://github.com/YunYouJun/valaxy/pull/842)
