Valaxy 1.4.0 adds glass navigation to the Yun desktop homepage and removes two legacy APIs.

## Yun theme

- Set `banner.navStyle: 'glass'` for frosted navigation links on desktop and mobile. Use `pages[].iconColor` to color icons independently.
- Homepage social icons show their brand colors on hover and keyboard focus. Article and collection cards, tags, and pagination use updated borders and hover colors.
- Returning to the top interrupts an in-progress scroll. The controls respect reduced motion, and glass surfaces use solid backgrounds with increased contrast or reduced transparency.

## Compatibility changes

- The `codepen: true` frontmatter flag and `useCodePen()` have been removed. Use the CodePen addon component, an iframe, or load the script explicitly for existing embed markup.
- `pageTitleClass` and `postTitleClass` are typed by `valaxy-theme-yun`. Existing YAML still works in Yun. TypeScript projects using Yun can import the theme declarations for completion and type checking.

See the [1.4.0 migration guide](https://valaxy.site/migration/version#v140) for examples.
