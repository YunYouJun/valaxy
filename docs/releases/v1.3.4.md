Valaxy 1.3.4 keeps missing pages out of search indexes and fixes several build and rendering issues.

- Pages using the `404` layout emit `noindex` and omit the canonical link. Client-side navigation restores the expected metadata when leaving a 404 page. Your host still controls the HTTP status.
- Source-relative images in RSS entries and post excerpts resolve from the Markdown file that contains them.
- Builds use consistent Vite config precedence and respect settings such as `configFile`, `base`, and `outDir` across the client and SSG passes.
- Static rendering, encrypted content, code-group labels, and client listener cleanup are more reliable.
