Valaxy 1.3.0 ships less JavaScript on the homepage, loads KaTeX fonts only where they are used, and defers Fuse until the first search. This release also changes two defaults for sites with custom tooltips or runtime Vue templates. Review the upgrade notes before updating.

## Upgrade notes

- **Floating Vue is no longer registered by Valaxy.** Footnote previews use Reka UI. Remove `floatingVue` and `footnote.preview` from your site config. If your own code uses `v-tooltip` or other Floating Vue APIs, migrate those components or install and register Floating Vue explicitly. See the [migration guide](https://valaxy.site/migration/version#v130).
- **Browser template compilation now defaults to `'lazy'`.** Valaxy loads the Vue compiler when it renders an HTML excerpt or decrypted template. Use `ValaxyDynamicComponent` for custom template strings, or set `vue.browserTemplateCompilation: true` in `valaxy.config.ts` if your own code uses Vue's `template` option or calls `compile()` directly in the browser. Set `false` to disable browser compilation entirely.
- **Frontmatter uses the YAML 1.2 core schema** in both rendering and DevTools. Review values that depended on YAML 1.1 implicit typing, and quote values that should remain strings. ([#799](https://github.com/YunYouJun/valaxy/pull/799))

## Measured homepage performance

We built the same [real Yun blog at `045221d`](https://github.com/YunYouJun/yunyoujun.github.io/tree/045221de24a1457660164f3ea108d55b43b1c953) with Fuse search. We compared npm `1.2.2` with `1.3.0` release tarballs installed outside the Valaxy workspace. These are the first-party assets requested on a cold Chromium homepage visit before opening search. Compressed size is the sum of the Brotli sizes of the requested JS files.

| Metric | npm `1.2.2` | `1.3.0` candidate | Change |
| --- | ---: | ---: | ---: |
| Homepage JS, raw | 1,673.7 KB | 754.3 KB | −55% |
| Homepage JS, Brotli | 424.7 KB | 233.5 KB | −45% |
| KaTeX font requests on the homepage | 39 (559.3 KB) | 0 | −39 requests |

- **[#803](https://github.com/YunYouJun/valaxy/issues/803):** The non-math homepage no longer requests KaTeX fonts. The tested math article rendered normally with the two fonts it used. DocSearch, Waline, and GSAP stayed out of the homepage requests. When fireworks are disabled, the homepage does not load `animejs` either.
- **[#805](https://github.com/YunYouJun/valaxy/issues/805):** Opening the homepage requests neither Fuse nor `valaxy-fuse-list.json`. The first search for `高斯模糊` returned the real article, including under simulated network throttling. In the separate before/after test for this fix, deferring Fuse removed about **27 KB raw / 8 KB Brotli** from the initial JS.

These figures describe one site and its configuration. Theme options, addons, and content affect the results.

## Other changes

- Page layouts load on demand in production, with the active layout resolved before rendering or hydration. Yun shows homepage content before the intro on mobile, defers its optional serif font, and reduces startup and scroll work.
- Yun improves mobile navigation labels and collection cards. The demo ships smaller local images and removes overrides that duplicated core UI. ([#806](https://github.com/YunYouJun/valaxy/pull/806))
- Drafts and private heading metadata stay out of public build artifacts. Share images, descriptions, canonical URLs, and feed metadata better reflect the published page. ([#801](https://github.com/YunYouJun/valaxy/pull/801))
- Markdown edits refresh post lists, tags, and categories from updated route metadata during development.
- New blogs deploy to GitHub Pages using the pinned pnpm version, Node.js LTS, and the official Pages actions. ([#800](https://github.com/YunYouJun/valaxy/pull/800))
