Valaxy 1.5.0 introduces Markdown author notes with a wide-screen Yun margin rail, collapsible page outlines, adaptive header anchor copy feedback, and a unified ad board card component.

## Markdown & Core

- Added Markdown author note syntax (`[^author-*]`) with distinct inline styling and accessible hover/tap preview popovers (`ValaxyFootnoteTooltip`) alongside standard footnotes (#834).
- Refined Markdown header anchors with adaptive desktop/inline layout, automatic link copying with pop feedback, `--va-header-anchor-*` CSS variables, and an exported `copyToClipboard` helper (#832).
- Updated `useActiveAnchor` to measure active outline rows relative to the marker container and refresh on container resize, keeping the indicator aligned across collapsed branches and responsive headers.

## Yun theme

- Added a wide-screen right-hand author note rail (`YunAuthorNotes`) aligned to prose references with collision avoidance, full-width code/table card layout, bidirectional jump navigation, and a persisted toolbar toggle (#834).
- Added collapsible outline sections (`outlineCollapsible?: boolean | 'auto'`), an expand/collapse-all header control, smooth accordion transitions, and visible-ancestor active marker fallback.
- Added `<YunAdBoardCard>` for consistent sidebar and mobile ad board styling, redesigned post status bookmarks (`YunPostStatusIcons`) and draft card borders, and aligned mobile bottom cards.

## Build & CI

- Triggered EdgeOne production deployments for docs and Yun demo directly from published release tags (#830).
- Fixed flaky test timeouts and optimized Vitest, Playwright, and CI workflows (#833).
