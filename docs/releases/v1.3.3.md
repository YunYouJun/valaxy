Valaxy 1.3.3 fixes static publishing and keeps build machine paths out of the client configuration.

- The sitemap uses the canonical URLs from rendered pages, lists each URL once, and preserves a site's custom `robots.txt`.
- SSG keeps `404.html` for the host's fallback and no longer writes `404/index.html` or includes the fallback in the sitemap. If a host serves `/404` directly as a regular page, configure its HTTP status separately.
- Production bundles no longer include the local project root or Node-only addon resolution details in the client configuration. Addon options and props are still available to components.
- The site author and Yun article author include the configured public `author.email` in their JSON-LD. Sites with an empty email continue to omit it.
