Valaxy 1.3.1 fixes an intermittent layout jump on first load and lets Yun display the desktop homepage content while its decorative intro runs.

- The flash-of-unstyled-content guard waits for the page's stylesheets before showing the page. The whole-page fade was removed so Chrome can record the first visible content reliably.
- Yun renders the avatar, site introduction, and navigation in the initial HTML without hiding them until the intro finishes. The banner, divider, and avatar effects keep their existing animation.
- `themeConfig.serifFont` can skip Yun's full Noto Serif SC stylesheet on the home layout (`'except-home'`) or on all layouts (`'off'`). Existing sites retain the default (`'all'`).

We tested the changes on a real Yun blog. In a cold desktop Lighthouse comparison, median LCP fell from 1.50 s to 0.78 s. Mobile LCP was essentially unchanged. Browser regressions cover delayed styles, visible home content before application JavaScript arrives, and Fuse loading on the first search.
