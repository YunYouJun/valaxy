Valaxy 1.3.2 fixes the Yun desktop homepage intro so the centered banner and the author profile no longer overlap.

- The site title fades for 150 ms as the two decorative lines retract. The profile appears only when both lines finish, then fades in over 300 ms with a 5 px rise.
- Mobile keeps the profile visible while the decoration plays in the gutter. Desktop also shows the profile directly with reduced motion, without JavaScript, or if the entry script arrives after the CSS fallback.
- Fuse and the search index still load only when the visitor opens search.
