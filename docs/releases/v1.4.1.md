Valaxy 1.4.1 unifies Yun interactive controls, secondary page cards, and dark-mode color hierarchy, alongside SSG docs and deployment refinements.

## Yun theme

- Unified action buttons (`.yun-action-btn`) and shared mobile drawer headers (`YunDrawerHeader`) across the navbar, hamburger menu, search dialog, local outline, local outline button, and side drawers (#825).
- Refined sidebar navigation links, social icon soft tints, and `/projects` showcase cards with accessible filter pills (#826).
- Redesigned `/albums` into a responsive paper card grid, upgraded `YunSponsor` with responsive dark-safe QR cards, and aligned `YunPostActions`, `YunPostNav`, `YunPostCollapse`, and `YunNotice` with shared surface tokens (#827).
- Established a four-tier dark-mode surface elevation ladder (`--yun-bg-elevated` inheriting `--va-c-bg-elevated`), visible dark `--yun-surface-line`, and adaptive sky-blue `--va-c-link`, plus updated `ValaxyCopyright`, `YunMdTimeWarning`, `YunAiExcerpt`, `YunCategory`, neutral Markdown tables, cloud-ornament `<hr>` dividers, and dark footer gradient (#828).
- Centered the mobile home intro and fixed post tag badge container styling.

## Build & CI

- Split route-level styles in documentation SSG builds (#823) and advance EdgeOne production mirrors after tagged releases (#824).
